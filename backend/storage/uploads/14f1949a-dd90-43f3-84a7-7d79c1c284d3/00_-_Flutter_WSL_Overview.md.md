## 🧠 Filosofi Setup Ini

Kita tidak menggunakan Android Studio karena:

- Fokus satu editor (VS Code)
- Setup lebih ringan
- Lebih fleksibel untuk environment Linux
- Cocok untuk developer backend/fullstack
